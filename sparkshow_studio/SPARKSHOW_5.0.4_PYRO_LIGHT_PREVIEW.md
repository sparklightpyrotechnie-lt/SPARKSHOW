# Sparkshow Studio 5.0.4 — Pyro Light Preview

Adds a dedicated Light Preview mode for Pyro effects.

## Light Preview

Enabled by default. It reduces preview-only geometry budgets while preserving the user-visible effect controls:

- Fountain: up to 8 jets / 48 sparks / 3 curve samples
- Crackling: up to 40 main stars / 2 branch levels
- Falling Stars: up to 40 stars
- Day Smoke: up to 8 puffs / 6-segment puff mesh

Disable **Light Preview** for the full configured preview budget.

Pyro objects remain in the dedicated **Sparkshow Pyrotechnics** collection and are never linked to drone family collections.
