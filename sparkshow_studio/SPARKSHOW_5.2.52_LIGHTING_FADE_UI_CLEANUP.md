# Sparkshow Studio 5.2.52

## Lighting
- Added gradient effect fade-in and fade-out controls in frames.
- The fade envelope is applied by the shared effect engine used by Live Preview and Bake.
- Uniform (UNI) lighting remains unchanged by the new gradient fade controls.
- Existing gradient effects, Line Draw fades, and Pulse minimum intensity are preserved.

## UI cleanup
- Removed the user-facing Visual UI settings panel and its property module.
- Removed editable per-section card colour controls.
- Section headers/icons remain available with fixed presentation.

## Compatibility
- Existing lighting properties remain readable.
- Legacy Visual UI properties are no longer registered by Sparkshow Studio.
