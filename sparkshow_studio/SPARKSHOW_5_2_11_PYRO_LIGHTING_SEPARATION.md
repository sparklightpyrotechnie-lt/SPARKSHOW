# Sparkshow Studio 5.2.12 — Pyro / Lighting Separation

Pyro is intentionally independent from Drone Lighting.

A drone can emit its own programmable RGBW light and, separately, trigger a Pyro profile. Fire events use the assigned Pyro profile color and parameters only. Day Smoke no longer inherits the drone's RGBW color.

Collections remain separate:
- Families: drones and anchors only
- Sparkshow Pyrotechnics: live Pyro preview
- Sparkshow Pyro Bake: renderable baked Pyro
