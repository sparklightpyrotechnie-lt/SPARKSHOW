# Sparkshow Studio 5.1.1 – Section colors

Blender 4.1 does not expose a supported API for assigning arbitrary background colors to individual Panel instances.
This UI revision therefore uses persistent colored header accents and card boxes for each section:
- SHOW: blue
- LIGHTING: violet
- PYRO: orange
- SYNOPTIC: teal
- SAFETY: green
- EXPORT: slate

The accents are implemented with Blender preview icons so they remain visible across Blender themes without changing the user's global UI theme.
